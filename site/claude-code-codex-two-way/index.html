Guide

Make Claude Code and Codex talk to each other.

Agents Bridge for Claude Code and Codex connects a Claude Code chat and a Codex Desktop chat on the same Mac so they message each other directly, in both directions. Either chat can start; both stay open in their own apps while you watch, and each keeps its own context. That is different from one-way delegation, where one agent runs the other as a background tool and gets one answer back.

Two real chats vs one-way delegation

Delegation plugins make one agent call the other as a background tool: a fresh run that hands back one answer. That works well for a quick second opinion. The bridge connects two conversations instead.

How a message arrives

A message from the other chat steers the receiving chat's current turn, or starts a turn when it is idle. A running tool is never interrupted. The message arrives marked as input from another agent, and the receiving chat answers it in the same collaboration. Text from the other agent carries no authority: it can't grant permissions or approve anything on your behalf.

Start it from either side

you → claudeCollaborate with Codex. Review this plan and challenge its assumptions.you → codexCollaborate with Claude. Review this plan and challenge its assumptions.

The chat asks three short questions: editing, limits, and whether to start with a new chat in the other app. Answer Yes, or open the panel to pick a chat you already have open. A new Claude chat requested this way always opens in Claude Desktop; to use a terminal chat, start claude in the project folder first and pick it in the panel.

Longer work in one conversation

  • Phases. "Plan this feature with Codex, then implement it phase by phase" runs as one collaboration; one approval covers every phase.
  • Editing. Off until you allow it, within the scope you write. Local edits and commits only unless your scope says otherwise, and each app's own approval prompts still apply.
  • Shared files. The bridge does not lock files. When both agents edit, give them separate files or separate worktrees.
  • Control. Pause, finish or export (Markdown or JSON) from the panel at any time.

FAQ

Frequently asked questions

Can Claude Code and Codex talk to each other directly?

Yes. Agents Bridge for Claude Code and Codex connects a Claude Code chat and a Codex Desktop chat on the same Mac. After you approve, they send each other messages directly, and you follow the conversation in a local panel.

Is it two-way, or only Claude calling Codex?

Two-way. Either chat can start a collaboration, and both send and answer messages within it.

Do both apps need to stay open?

Yes. Codex Desktop must be running, and the Claude chat must be open in the Code tab of Claude Desktop or as an interactive claude chat in a terminal.

Does it work with the Codex CLI or claude -p?

Not yet for the Codex CLI; support is planned. Non-interactive Claude (claude -p), the VS Code extension and the SDK are not supported.

Is anything sent to a server?

The bridge itself sends nothing off your machine: messages travel over local sockets and the Codex app's connection, and history stays in a private file on your Mac. The models still run through their own providers, as they always do.

What stops the two agents from talking forever?

The limits you set. Message count and deadline apply to both directions, and you can pause or finish the collaboration from the panel at any time.

Install

Two commands per app.
Then just ask.

Installs as agents-bridge.

For macOS. You need Claude Code 2.1.224 or later, in the Code tab of Claude Desktop or as claude in a terminal; Codex Desktop running (support for the Codex CLI is coming); Bun 1.4 or later; and Git.

  1. 01 Install the Codex side

    codex plugin marketplace add jaimebernalm/agents-bridge
    codex plugin add agents-bridge@jaimebernalm

    In Codex, open Agents Bridge in the plugins and trust both hooks. Then open a new Codex chat.

  2. 02 Install the Claude side

    claude plugin marketplace add jaimebernalm/agents-bridge
    claude plugin install agents-bridge@jaimebernalm

    Then open a new Code chat in Claude Desktop, or start claude in a terminal in the project folder.

  3. 03 Check that they see each other

    Open the same project folder in both apps and ask either chat: “Use Agents Bridge to list the chats in this folder.” Not listed? See Troubleshooting.
