codex-plugin-cc vs Agents Bridge: which one fits?

They solve different problems. OpenAI's codex-plugin-cc lets Claude Code hand work to Codex with slash commands such as /codex:review, /codex:adversarial-review and /codex:rescue, and get the result back. Running codex exec from a shell does a similar one-shot job without a plugin. Agents Bridge for Claude Code and Codex connects two chats that are already open, a Claude Code chat and a Codex Desktop chat, for a conversation over many steps that either side can start. For a quick one-way review or task, codex-plugin-cc is the simpler choice.

When codex-plugin-cc is the better fit

  • You want a quick, read-only review of your uncommitted changes or your branch, and one answer: /codex:review.
  • You want Codex to challenge a design's choices and assumptions in one pass: /codex:adversarial-review.
  • You want to hand Codex a bug and keep working while it runs in the background: /codex:rescue --background, then /codex:status and /codex:result.
  • You want to carry the current Claude Code session into a Codex thread: /codex:transfer.
  • You want Codex to review each Claude response automatically: its optional review gate does that, though its own docs warn it can use up your limits quickly.
  • You use the Codex CLI rather than Codex Desktop, or you work on Linux. Agents Bridge needs Codex Desktop on macOS.

When codex exec is the better fit

  • You're scripting: a CI job, a pre-commit check or a batch of prompts.
  • You want nothing installed beyond the Codex CLI.
  • One prompt and one printed output is all you need.

When Agents Bridge is the better fit

  • You want both agents in the conversation, asking each other questions and answering over many steps.
  • You want to start from Codex as well as from Claude.
  • You want the other agent to be your existing chat, with what it already knows about the project.
  • You want to approve and follow the collaboration: limits, pause, finish and export in a local panel, with editing off until you allow it.
  • You want a record of who said what, with disagreements kept instead of a single merged answer.
  • You want them to plan and then build phase by phase under one approval.

Can I use both?

Yes. They are independent plugins, so you can install both and choose per task: a slash command for a quick review, the bridge for longer work together.

FAQ

Frequently asked questions

Is Agents Bridge made by OpenAI or Anthropic?

No. Agents Bridge for Claude Code and Codex is an independent, MIT-licensed project, not affiliated with Anthropic or OpenAI. codex-plugin-cc is OpenAI's own plugin.

Which is better for code review?

For a quick one-shot review of uncommitted changes, codex-plugin-cc's /codex:review is simpler. For a review where the reviewer can ask questions, the author can answer, and the fixes go back to the chat that wrote the code, Agents Bridge fits better.

Does codex-plugin-cc work from Codex to Claude?

Its commands start in Claude Code and send work to Codex. Agents Bridge works in both directions: either chat can start.

Does Agents Bridge work with the Codex CLI?

Not yet. It delivers messages into a Codex Desktop chat, so Codex Desktop must be running on macOS. Support for the Codex CLI is planned.

Do I need to pay for any of these?

All three are free to use. codex-plugin-cc and codex exec use your ChatGPT plan or OpenAI API key; Agents Bridge uses your normal Claude and Codex subscriptions and makes no model calls of its own.

Install

Two commands per app.
Then just ask.

Installs as agents-bridge.

For macOS. You need Claude Code 2.1.224 or later, in the Code tab of Claude Desktop or as claude in a terminal; Codex Desktop running (support for the Codex CLI is coming); Bun 1.4 or later; and Git.

  1. 01 Install the Codex side

    codex plugin marketplace add jaimebernalm/agents-bridge
    codex plugin add agents-bridge@jaimebernalm

    In Codex, open Agents Bridge in the plugins and trust both hooks. Then open a new Codex chat.

  2. 02 Install the Claude side

    claude plugin marketplace add jaimebernalm/agents-bridge
    claude plugin install agents-bridge@jaimebernalm

    Then open a new Code chat in Claude Desktop, or start claude in a terminal in the project folder.

  3. 03 Check that they see each other

    Open the same project folder in both apps and ask either chat: “Use Agents Bridge to list the chats in this folder.” Not listed? See Troubleshooting.
