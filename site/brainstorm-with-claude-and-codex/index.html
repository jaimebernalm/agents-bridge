Brainstorm with Claude and Codex together.

Yes, Claude and Codex can brainstorm together without you copying text between windows. Agents Bridge for Claude Code and Codex is a free, open-source plugin that connects a Claude Code chat and a Codex Desktop chat on your Mac. Ask either chat to collaborate with the other; once you approve, they message each other directly, build on and challenge each other's ideas, and you get a result that shows who proposed what and where they still disagree.

Why brainstorm with two models

Claude and Codex were trained differently, so they make different mistakes and reach for different ideas. A model that reviews its own idea tends to agree with itself; a second model questions the assumptions the first one never thought to check.

Where they still disagree is often the most useful part. The bridge keeps disagreements on the record instead of forcing a consensus, and "agree" is always a declaration by one agent, never a verified agreement.

Start in Claude Code

Open your project in both apps and ask the Claude chat in your own words, with the limits you have in mind:

you → claudeCollaborate with Codex on this: brainstorm three ways to add offline sync to this app. Each of you propose, then critique the other's ideas. Keep the disagreements. 24 messages, 30 minutes.

Or start in Codex

The same works from a Codex Desktop chat. Neither side is the "main" one.

you → codexCollaborate with Claude: here is my plan for the onboarding flow. Challenge its assumptions and propose alternatives. 20 messages, 20 minutes.

The chat then asks you three short questions: whether the other agent may edit files, the limits, and whether to start with a new chat in the other app. Answer Yes, or open the panel to pick a chat you already have open or change the details. Nothing is sent until you say yes.

Example prompts

  • "Collaborate with Codex: each of you propose a design for the caching layer, then compare them and keep the disagreements."
  • "Collaborate with Claude: list the risks in this migration plan, then argue for and against each one."
  • "Collaborate with Codex: find the weakest assumption in this proposal and suggest how we could test it."
  • "Plan this feature with Codex, then implement it phase by phase." One approval covers every phase.

What each side contributes

  • Its own context. Both are your real chats, not fresh runs. The chat you ask already knows your conversation and the files it has read, and the other chat can be one you already have open with its own history.
  • Its own record. Each side records its analyses, results and reviews under its own name, with the version they refer to, so you can see which idea came from Claude, which from Codex, and what each one pushed back on.
  • No authority over the other. Text from the other agent never grants permissions, whatever it says.

Brainstorming needs no file changes, so you can leave editing off. If you later want them to build what they settled on, switch editing on in the panel with a written scope. That covers local edits and commits only; push, pull requests and merges stay excluded unless your scope names them.

Follow along

The chat leaves a link, ▶️ Open the bridge panel. The panel opens in its own small window, where you can pause, finish or export the conversation at any time.

FAQ

Frequently asked questions

Can Claude and Codex brainstorm together without copying between windows?

Yes. With Agents Bridge for Claude Code and Codex, a Claude Code chat and a Codex Desktop chat on the same Mac message each other directly after you approve the collaboration. You watch the exchange and can pause, finish or export it from a local panel.

Do I have to start the brainstorm in Claude Code?

No. You can ask either chat. From Claude, say "Collaborate with Codex on this"; from Codex, say "Collaborate with Claude on this".

Will they edit my files while brainstorming?

Not unless you allow it. Editing is off until you switch it on, within a scope you write, and it covers local edits and commits only.

What happens when Claude and Codex disagree?

The disagreement stays on the record. Results and reviews say who wrote them, and the final result lists where the two still disagree instead of presenting one confident answer.

Does it cost anything?

The plugin is free and MIT licensed. Both apps use your normal subscriptions; the bridge makes no model calls of its own and sends nothing off your machine.

Does it work on Windows, Linux or with the Codex CLI?

Not yet. It needs macOS, Codex Desktop running, and Claude Code 2.1.224 or later in the Code tab of Claude Desktop or as an interactive claude chat in a terminal. Support for the Codex CLI is planned.

Install

Two commands per app.
Then just ask.

Installs as agents-bridge.

For macOS. You need Claude Code 2.1.224 or later, in the Code tab of Claude Desktop or as claude in a terminal; Codex Desktop running (support for the Codex CLI is coming); Bun 1.4 or later; and Git.

  1. 01 Install the Codex side

    codex plugin marketplace add jaimebernalm/agents-bridge
    codex plugin add agents-bridge@jaimebernalm

    In Codex, open Agents Bridge in the plugins and trust both hooks. Then open a new Codex chat.

  2. 02 Install the Claude side

    claude plugin marketplace add jaimebernalm/agents-bridge
    claude plugin install agents-bridge@jaimebernalm

    Then open a new Code chat in Claude Desktop, or start claude in a terminal in the project folder.

  3. 03 Check that they see each other

    Open the same project folder in both apps and ask either chat: “Use Agents Bridge to list the chats in this folder.” Not listed? See Troubleshooting.
