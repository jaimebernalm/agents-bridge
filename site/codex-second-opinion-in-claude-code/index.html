Guide

A Codex second opinion in Claude Code, with the full context.

To get a second opinion from Codex without starting from zero, connect the Codex chat you already use. Agents Bridge for Claude Code and Codex lets your Claude Code chat ask a Codex Desktop chat to review a plan, a diff or a diagnosis, and it works the other way too: Codex can ask Claude. The reviewer is a real chat with its own history, not a fresh headless run, and the two can go back and forth until each point is settled or recorded as a disagreement.

Ask from Claude Code

With the project open in both apps, ask your Claude chat:

you → claudeCollaborate with Codex: review the change I just made in src/api and list concrete defects. 12 messages, 15 minutes.

Ask from Codex

The other direction is the same idea:

you → codexCollaborate with Claude: give me a second opinion on this diagnosis of the flaky sync test. Tell me what I've missed. 12 messages, 15 minutes.

The chat asks you three short questions: whether the other agent may edit files, the limits, and which chat to use. Answer Yes to start, or open the panel to choose an existing chat or change the details.

Why context matters for a second opinion

A fresh run only sees what you hand it, and it hands back one answer. Here, the chat asking for the review already knows your conversation and briefs the other one. If you pick a chat that has already worked on the project, the reviewer brings its own history too. When something is unclear, the reviewer can ask, and the answer comes back to the chat that wrote the code, with the context to fix it.

What you get back

Reviews are recorded with who wrote them and which version of the result they refer to. Agreement is a declaration by an agent, and open disagreements stay visible, so you know what to double-check.

result v2 · by claudeFix the 429 retry; surface the fetchUser timeout.review of v2 · by codexAgree on the retry. Disagree on the timeout: it is handled upstream.Disposition: proposal, with disagreements

When a one-shot review is enough

If you only want a quick read-only review of your uncommitted changes and one answer, OpenAI's codex-plugin-cc does that from Claude Code with /codex:review. See how the two compare.

FAQ

Frequently asked questions

How do I get a second opinion from Codex in Claude Code?

Install Agents Bridge for Claude Code and Codex in both apps, open the project in Claude Code and Codex Desktop, and ask the Claude chat something like "Collaborate with Codex: review this change and list concrete defects." Approve the three questions it asks, and the two chats talk directly.

Can Codex get a second opinion from Claude?

Yes. Either chat can start. Ask the Codex chat "Collaborate with Claude: review this plan" and the same flow runs in the other direction.

Does the reviewer see my whole conversation?

It sees what the asking chat sends it. If you pick a chat that already worked on the project, it also keeps its own history. Because it is a real conversation, the reviewer can ask follow-up questions instead of guessing.

Can the reviewer change my code?

Only if you allow it. Editing is off until you switch it on in the panel or answer yes to that question, within a scope you write, and it covers local edits and commits only.

How is this different from /codex:review?

codex-plugin-cc runs a Codex review from Claude Code and returns its result as a job. Agents Bridge connects two chats that can both start, ask and answer over many messages. For a quick one-shot review, codex-plugin-cc is simpler.

Install

Two commands per app.
Then just ask.

Installs as agents-bridge.

For macOS. You need Claude Code 2.1.224 or later, in the Code tab of Claude Desktop or as claude in a terminal; Codex Desktop running (support for the Codex CLI is coming); Bun 1.4 or later; and Git.

  1. 01 Install the Codex side

    codex plugin marketplace add jaimebernalm/agents-bridge
    codex plugin add agents-bridge@jaimebernalm

    In Codex, open Agents Bridge in the plugins and trust both hooks. Then open a new Codex chat.

  2. 02 Install the Claude side

    claude plugin marketplace add jaimebernalm/agents-bridge
    claude plugin install agents-bridge@jaimebernalm

    Then open a new Code chat in Claude Desktop, or start claude in a terminal in the project folder.

  3. 03 Check that they see each other

    Open the same project folder in both apps and ask either chat: “Use Agents Bridge to list the chats in this folder.” Not listed? See Troubleshooting.
