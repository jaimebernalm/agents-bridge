Open source plugin · macOS · Desktop apps

Your Claude chat and your Codex chat, working together.

Ask either chat to work with the other one. Answer three short questions, and the two agents message each other directly while you watch. At the end you get a result that shows who said what, and where they still disagree.

Install in 5 minutes View on GitHub

Free and MIT licensed. Uses your existing subscriptions. Makes no model calls and sends nothing off your machine.

Why have them collaborate?

They catch each other's mistakes

Two different models make different errors. When one reviews the other's plan or code, problems a single agent would miss tend to surface.

Disagreements stay visible

You see where they disagree instead of getting one confident answer, so you know exactly what to double-check.

Everything is traceable

Every message, result and review is recorded with its author and the exact version it refers to. Export the whole exchange as Markdown or JSON.

How it works

  1. 1

    Ask in either chat

    Describe what you want in plain words, from Claude or from Codex. For example: Plan this feature with Codex, then implement it phase by phase. 40 messages, 45 minutes.

  2. 2

    Answer three questions

    Editing: may the other agent edit files and make local commits? Limits: how many messages and how much time? Start: go, or adjust it first in the panel. Nothing is sent until you say yes.

  3. 3

    Watch them work

    The two chats message each other directly. A small local panel lets you pause, finish or export at any time.

  4. 4

    Get a result with authorship

    Versioned results, reviews of exact versions, and the disagreements that remain. "Agree" is a declaration by an agent, never a fake consensus.

Ideas to try

  • Review — “Have Claude review the change Codex just made and list concrete defects.”
  • Plan, then build — “Plan this feature with Codex, then implement it phase by phase.”
  • Debug — “Each of you investigate why this test is flaky, then compare your findings.”
  • Design — “Compare two approaches to the caching layer and keep the disagreements.”

Two live chats, not a delegated job

Plugins like OpenAI's codex-plugin-cc let Claude Code hand reviews and tasks to Codex, resume those jobs, or transfer the session into a Codex thread. That's a great fit for delegating work. The bridge does something different: it connects the Claude and Codex Desktop chats you already have open, so they can talk to each other.

Delegating a review or a task to Codex? codex-plugin-cc does that well. Want the two agents to plan, investigate or build something together over several steps? That's what the bridge is for.

You stay in control

Nothing starts without you

A chat can suggest a collaboration; only you start it. The bridge reads your answer from the app itself, never from what an agent says.

Editing is opt-in

The other agent edits only if you allow it, within the scope you write. Push, pull requests, merges and deploys stay excluded unless your scope names them.

Messages carry no authority

Text from the other agent never grants permissions, whatever it says.

Limits are enforced

Message count and deadline apply in both directions.

Nothing is sent twice

If a delivery is uncertain, the bridge shows it as uncertain and does not resend it.

It stays local

Messages travel over local sockets and the Codex app's connection. History lives in a private SQLite file on your machine.

Install in about 5 minutes

Desktop apps only, for now. The bridge connects Claude Desktop (Code tab) with Codex Desktop on macOS. The Claude Code CLI and Codex CLI are not supported yet; support is planned.

You need

  • macOS
  • Codex Desktop, running
  • Claude Desktop, Code tab (Claude Code 2.1.224 or later)
  • Bun 1.4 or later
  • Git

  1. Install the Codex side

    codex plugin marketplace add jaimebernalm/cc-cdx-bridge
    codex plugin add cc-cdx-bridge@jaimebernalm

    Open Codex, find Claude ⇄ Codex Bridge in its plugins and trust both hooks. Then open a new Codex chat.

  2. Install the Claude side

    claude plugin marketplace add jaimebernalm/cc-cdx-bridge
    claude plugin install cc-cdx-bridge@jaimebernalm

    Then open a new Code chat in Claude Desktop.

  3. Check that they see each other

    Open the same project folder in both apps and ask either chat:

    Use the Claude ⇄ Codex Bridge to list the chats in this folder.

    Not listed? See Troubleshooting.

Two agents. One result you can trust.
