How it works

No sessions to manage and no settings to edit. Ask in plain words.

  1. 1

    Ask either chat

    “Collaborate with Codex on this: review the error handling in src/api and propose fixes. 20 messages, 20 minutes.”

  2. 2

    Answer three questions

    May the other agent edit files? How many messages and how much time? Start now, or adjust it in the panel? Nothing is sent until you say yes.

  3. 3

    Watch them work

    The two chats message each other directly. Pause, finish or export from the panel at any time.

  4. 4

    Read the result

    Every result and review says who wrote it and which version it refers to, and the disagreements stay on the record.

Why two chats instead of one

Two different models make different mistakes. When one reviews the other's plan or code, problems a single agent would miss tend to surface.

  • They keep what they know. These are your real chats, with their history and the files they've already read.
  • Either one can start. Ask from Claude or from Codex; the other side is asked the same way.
  • Disagreements stay visible. You see where they still disagree, so you know what to check yourself.
  • One approval for a whole plan. Plan, then build phase by phase, without approving each step again.

You stay in control

The bridge reads your answers from the app itself, never from what an agent says.

  • Nothing starts without youYes, or Start in the panel
  • Editing by the other agentOff until you allow it
  • Push, pull requests, merges, deploysOnly if your scope names them
  • Authority of the other agent's messagesNone
  • Message and time limitsEnforced both ways
  • Uncertain deliveriesShown, never resent
  • Where your history livesA private file on your Mac
  • Model calls made by the bridgeNone

Not a delegated job

codex-plugin-cc lets Claude Code hand reviews and tasks to Codex, resume those jobs, or transfer the session into a Codex thread. It's a good fit for delegating. The bridge connects two chats that are already open, for an exchange that runs over many steps.

Install

About five minutes. Desktop apps on macOS only, for now: the Claude Code CLI and Codex CLI aren't supported yet.

macOS
Claude DesktopCode tab, Claude Code 2.1.224 or later
Codex DesktopRunning
Bun1.4 or later
Git

  1. Install the Codex side

    codex plugin marketplace add jaimebernalm/cc-cdx-bridge
    codex plugin add cc-cdx-bridge@jaimebernalm

    In Codex, open Claude ⇄ Codex Bridge in the plugins and trust both hooks. Then open a new Codex chat.

  2. Install the Claude side

    claude plugin marketplace add jaimebernalm/cc-cdx-bridge
    claude plugin install cc-cdx-bridge@jaimebernalm

    Then open a new Code chat in Claude Desktop.

  3. Check that they see each other

    Open the same project folder in both apps and ask either chat: “Use the Claude ⇄ Codex Bridge to list the chats in this folder.” Not listed? See Troubleshooting.
